# WO8a — executive summary (for Opus / next-WO scoping)

**One line:** the first environment↔culture correspondence probe passed its positive-control gate —
the instrument is calibrated — and in doing so it established that **environment sets outer bounds on
culture, it does not determine it**. Companion detail: `wo8a_findings.md`.

## What WO8a was

A descriptive notebook (no engine/API/UI): build the shared **society → basin → EDOPS signature**
substrate (1,133 Ethnographic-Atlas societies joined to L08 basins, matches WO4), then *draw* how the
near-tautologically-environmental control trait — **EA042 subsistence** (forager / pastoralist /
farmer) — sorts across environmental space, before any statistical test. Accept gate: does it visibly
separate? It ran no test; that is WO8b.

## What we found

1. **Gate PASSED.** EA042 separates — cleanest in the **Climate envelope** bet (aridity + precip +
   runoff + annual temperature + seasonal amplitude). Water alone is a one-axis floor (poles separate,
   middle jumbled); adding temperature opens a real second axis that resolves foragers (cold) from
   pastoralists (warm-dry); adding terrain (Landscape) *smears* — elevation is subsistence-neutral.
2. **Rainfall seasonality is orthogonal to subsistence.** Timing, curve-shape, and modality-class all
   fail to separate EA042 — *how much* water and *how warm* matter, not *when* the rain falls. This
   refuted the WO's own expectation that the modality class would separate cleanest. (The raw 12-month
   curve remains the faithful representation if a seasonality term is ever wanted; the scalar carries
   the Mombasa two-peaks-cancel bug.)
3. **A coarse categorical corroborator lands crisp facts** the continuous view blurs: pastoralism →
   25% arid (vs ≤4%), intensive agriculture → arid only via irrigation, fishers/gatherers → cool-wet
   temperate coasts (the Pacific-NW pattern).
4. **Headline — environment as constraint, not determinant.** One near-hard wall (water for rain-fed
   agriculture), one soft gradient (temperature), broad human adaptability everywhere else. The
   instrument *showed* this rather than manufacturing separation — a credibility result.

## Implications going forward

- **The ruler is trustworthy but the signal is modest by nature.** EA042 is about as environmental as
  a cultural trait gets and it only *partially* separates. So 8c on a contested trait (EA034 high-gods,
  or another) should be framed around **an honest effect size + a defensible null**, not a hunt for
  strong separation. A null or dispersion-confounded result is a real finding here, not a failure.
- **8b's live decision is the metric, not the variables.** WO8a deliberately surfaced the
  composite-distance hazard (water variables inter-correlate 0.66–0.83; temperature↔amplitude −0.83,
  all < 0.90 so no catalog guard fires). z-scored Euclidean over-counts these blocks. 8b must choose —
  Mahalanobis, drop-to-representative, or keep-and-declare — *with the real question attached*.
- **Galton's problem is now the whole game.** Part of the forager↔cold separation is that foragers
  cluster at high latitudes — spatial/phylogenetic autocorrelation, not independent evidence. 8b's
  within-language-family restricted permutation (family crosswalk from WO4, 92.6%) is exactly the
  control for this; it is what turns "they co-occur" into "they co-occur beyond shared ancestry."

## Open questions for the WO author (teamwork — these may reshape 8b/8c)

1. **Is high-gods the right first contested trait?** Given the "bounds not determination" result, a
   trait with a stronger *a priori* environmental hypothesis (e.g. resource predictability → social
   complexity/storage) might be a fairer first real test than EA034. Worth a deliberate choice.
2. **Does the container caveat (13.4% of societies show a >2 °C basin-vs-site gap at L08) need
   handling before a significance test**, or is it tolerable noise a real effect survives? WO8a
   disclosed it, didn't correct it.
3. **Seasonality is non-load-bearing for *subsistence* — is it load-bearing for a different trait?**
   (Agricultural/ritual calendars, festival timing.) If so, keep the raw-curve channel live rather than
   dropping it.
4. **EA-only vs enrichment:** does the modest effect size argue for broadening beyond EA042/EA034 (the
   deferred D-PLACE enrichment) to get more traits × more societies before 8c, or does that dilute more
   than it adds?
