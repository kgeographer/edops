# regionality

V1 sub-phase: regional and non-global temporal datasets. Work orders, findings and trackers for this phase live here; scripts, notebooks and tests use a `regionality/` subfolder. Branch `regionality`.

Files here are prefixed `reg_` (lowercase) so they do not clash with other phases' WO files in the Opus project: `reg_woNN_<topic>.md` (the spec), `reg_woNN_results.md`, `reg_woNN_summary.md`. Notebooks, scripts and figures keep their `woNN_` names.
