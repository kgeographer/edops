# whgmodal

V1 sub-phase: the WHG environmental profile and the `/whgmodal` endpoint. Design and WO files to WO-10a are in `docs/design/dashboard/` (see `_INDEX.md` there); new material goes here.

The `wo07_*` to `wo10a_*` files in this folder are copies of the files of the same names in `docs/design/dashboard/`, made so they can be uploaded to the Opus project as a folder. The originals are canonical (code paths point there); do not edit the copies.
