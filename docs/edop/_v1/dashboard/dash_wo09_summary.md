# dash WO-09 summary: v1 alpha preparation

2026-11-18. Spec `dash_wo09_v1alpha-deploy-prep.md`; record `dash_wo09_results.md`. Branch `dashboard`. Nothing deployed; deployment follows `MAINTAIN_DEPLOY.md` and is Karl's and CC's.

- **A self-enclosed site (item 1).** One setting, `EDOPS_SITE_MODE=v1alpha`, set on the alpha service only (read per request; without it nothing changes). In that mode the 0.4 pages (`/sandbox`, `/sandbox/*`, `/workbench`, `/polities`, `/about`) answer 404 with a short page pointing at the live 0.4 site and back to `/edops`; every response is `noindex, nofollow` and `/robots.txt` disallows everything; a banner on every new page says "v1.0 alpha, November 2026, work in progress, not for citation" and links to live 0.4 (`EDOPS_LIVE_V04_URL`, default `https://edops.computingplace.org`). The Dashboard never linked to the Sandbox; the leak was Explorer, whose header showed Sandbox and Workbench pills, and the old profiles page. Explorer now uses the Dashboard header (Home, Dashboard, Using EDOPS, Data Explorer). The Documentation link and the documentation modal title carry a red "v0.4" tag in the alpha (the docs are the 0.4 docs).
- **Kept out of analytics; marked in the query log.** In the alpha the Google tag is not rendered. Its requests are written to `public.query_log` with `site = 'v1alpha'` (a new nullable column; 0.4 leaves it null), so the alpha's traffic can be told apart from 0.4's.
- **Using EDOPS (item 2).** A left column of small tiles (Overview first, then Societies, African Regions, Pueblo, WHG) that stays while the content changes on the right (`--use-nav-w`, 2/10 by default); `?tab=` opens a tab. Societies and African Regions show the existing Workbench page in embed mode (`/using/societies`, `/using/africa`: no header, no tab bar), so `workbench.html` stays the source. WHG holds the ten sample profiles (`/profiles` redirects to `/using?tab=whg`). Pueblo is a stub. Intro sentences and tile questions are placeholders (yellow) for Karl.
- **Time series stub (item 3).** A "Time series" tab after Similarity in the Dashboard: coming soon, an outline, a note that long Band T spans will point here.
