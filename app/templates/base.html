About EDOP

About EDOP

EDOP (Environmental Dimensions of Place) is an experimental platform for exploring the environmental context of historical and contemporary places. Building on geographer Carl Sauer's concept of cultural landscape—the mutually shaping relationship between physical environment and human activity—EDOP generates environmental "signatures" for locations worldwide using multi-scale datasets from global geographic realms to ecoregions down to 40km² subbasins. These signatures draw from over 190,000 hydrological units characterized across four temporal "persistence bands": physiographic bedrock (long-term geology and topography), hydro-climatic baselines (drainage, runoff, aridity), bioclimatic proxies (vegetation and productivity indicators), and Anthropocene markers (modern land use and human modification). This allows researchers to selectively query environmental conditions relevant to different historical periods and research questions.

Beyond environmental profiling, EDOP links these signatures with cultural and semantic data—including anthropological variables from the D-PLACE project covering subsistence, settlement, and social organization for over 1,200 documented societies, and for heritage cities, Wikipedia-derived discourse patterns across environment, history, culture, and modern themes. The platform supports queries like "Which ancient cities shared similar environmental constraints?" or "How does environmental context correlate with cultural patterns?" All functionality is exposed via API endpoints, enabling integration with existing gazetteer infrastructure such as the World Historical Gazetteer and Pleiades. EDOP is under active development and welcomes scholarly partnerships and institutional support.

Technical

EDOP assigns environmental signatures to geographic coordinates by identifying the HydroATLAS sub-basin (level 08, ~190k globally) containing each point. Each signature comprises 47 attributes spanning climate, terrain, hydrology, land cover, and soil characteristics—organized into persistence tiers from geological (stable over millennia) to anthropogenic (changing within decades).

Data Sources

  • BasinATLAS Framework: 190,000 sub-basins with 300 environmental attributes; we use level 08 (~190k basins, median 200 km²) and a subset of 47 attributes.
  • OneEarth Bioregions: 847 ecoregions in a 4-level hierarchy (Realms → Subrealms → Bioregions → Ecoregions)
  • Wikipedia: LLM-summarized descriptions for 821 ecoregions (96.9% coverage) and selected World Heritage sites and cities
  • World Historical Gazetteer: Place name resolution and coordinate matching

Stack

  • FastAPI + PostgreSQL/PostGIS + pgvector
  • 50-dimensional PCA vectors enable continuous similarity ranking via cosine distance
  • Frontend: Vanilla JavaScript + Leaflet + Bootstrap

API
RESTful endpoints return signatures, similarity rankings, and ecoregion metadata. Full interactive schema at /api/schema. Code at github.com/kgeographer/cedop.
