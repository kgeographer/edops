For the selected trait value, this counts how many societies fall in each OneEarth ecoregion and groups those ecoregions by biogeographic realm. Realms are ordered by total society count (most first); each realm lists its top three ecoregions with their counts. The map above marks every society holding the selected value in red, with other D-PLACE societies in gray, so realm concentration and geographic concentration can be read together.

What this does not show. These are raw counts, not shares of each realm's or ecoregion's total society population — a realm with more D-PLACE societies overall will tend to top this list for almost any trait value, simply because there are more societies to draw from, not necessarily because the trait is unusually concentrated there. Only the top three ecoregions per realm are shown, so a realm's true breadth can run wider than what's listed here. This is a descriptive count, not a test of association between environment and trait.
